# 竞彩足球数据分析工具

数据源：**中国体育彩票官方 API**（webapi.sporttery.cn），非第三方爬虫。

## 功能

- **在售赔率实时查看**：当前在售场次的胜平负固定奖金 + 让球线/让球赔率，支持手动刷新和 5 分钟自动刷新
- **历史相似赔率统计**：输入目标赔率 + 浮动百分比（如 2.5 ±8%），筛出历史同区间场次，输出胜/平/负分布与模拟投资回报率
- **一键更新历史数据**：按日期区间增量拉取（2015 年至今官方数据均可回溯），自动去重合并
- 数据落盘为 JSON + CSV（UTF-8 BOM，Excel 直接打开不乱码）

## 使用

### Windows 用户（exe）

到 [Releases](../../releases) 或 Actions 的 Artifacts 下载 `竞彩足球分析工具.exe`，双击即用，无需安装 Python。

> 首次运行会在 exe 同目录生成 `data/` 文件夹存放数据。杀毒软件若误报为 PyInstaller 打包程序，添加信任即可。

### 命令行（跨平台）

```bash
python jczq.py current                        # 抓当前在售场次
python jczq.py history 2026-09-01 2026-10-18  # 抓历史区间
python jczq_app.py                            # 启动图形界面
```

无第三方依赖，Python 3.8+ 标准库直接跑。

## 注意

- 官方历史接口只提供**收盘赔率**（停售时刻），无盘中变化轨迹
- 数据仅用于研究分析，请理性购彩
